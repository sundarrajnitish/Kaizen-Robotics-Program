Obstacle Avoider Robot

Level 1 · ATmega16 · Embedded C · OAR.c

Three IR proximity sensors look ahead, to the left and to the right. A sensor pulls its pin low when it sees something, so PIND = 0b11111111 means the way is clear. Each obstacle pattern has its own escape manoeuvre.

Click the floor to add a box, drag a box to move it, click a box to remove it. Drag the robot to move it, drag the blue dot to rotate it.

How it works

  1. The firmware reads all sensors at once with switch (PIND); a 0 bit means "obstacle on this side".
  2. An obstacle on one side only: the robot simply spins away from it until that sensor clears.
  3. Anything in front: it reverses for 300 ms, then turns for 300 ms (back_off_and_turn()).
  4. Boxed in on all three sides: it spins right for 2 seconds to find a way out.
  5. During a manoeuvre the code is inside _delay_ms(), so it does not look at the sensors until the move is finished.

Try this

  • Drive the robot into a corner (drag it there) and watch which case fires.
  • Build a narrow corridor out of boxes and see how the timed manoeuvres cope.
