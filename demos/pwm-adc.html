PWM & ADC Based Speed Control

Level 1 · ATmega16 · Embedded C

Pulse width modulation switches a pin fully on and off so fast that a motor or LED only "feels" the average. The longer the ON part of each period (the duty cycle), the brighter the LED or the faster the motor. The ADC lab sets the duty cycle from a potentiometer.

1. Pulse width modulation – PWM.c

PA0 alternates between a fast 50 ms / 50 ms pulse and a slow 1 s / 1 s pulse (3 s scope window).

How it works

  1. PWM.c drives PA0 high, waits with _delay_ms(), drives it low and waits again. The two timings show how the pulse width changes what you see.
  2. SpeedCntrl.c sets up the ADC (ADEN, prescaler /16, AVCC reference) and starts a conversion with ADSC. When ADIF is set the 10-bit result (0–1023) is in ADC.
  3. The reading sets the OFF time of a 25 ms software PWM period: t_off = reading / 40, t_on = 25 - t_off. A higher reading means a longer OFF time and a slower motor.
  4. At 870 and above the motors are switched off completely.
  5. Because _delay_ms() needs a constant, the cleaned-up code waits 1 ms at a time in a loop.
