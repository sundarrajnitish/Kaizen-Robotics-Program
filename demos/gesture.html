Gesture & Wireless Remote Control

Level 2 · Arduino · MEMS accelerometer

Two microcontrollers work together. The remote reads a MEMS accelerometer (or switches) and sends one-letter commands over a wireless serial link. The robot receives each letter and drives its motors. Drag the dot on the tilt pad to tilt the virtual accelerometer.

Drag the robot to move it, drag the blue dot to rotate it.

How it works

  1. The accelerometer outputs a voltage per axis that changes as it tilts. analogRead() turns it into a number from 0 to 1023; level is about 400 on each axis.
  2. The remote checks the reading against a window for each command (for example y between 415 and 475 means "reverse") and sends that letter with Serial.print() at 9600 baud.
  3. The receiver waits for Serial.available(), reads the letter and sets the motor driver pins.
  4. The pick and place version adds two DPDT switches on the remote. They drive the lift motor (z/y) and the gripper motor (x/w) on the robot's arm.

Try this

  • With Level2_Remote.ino, try to find the forward window: it is only 8 ADC counts tall (380–388), so the remote has to be held very precisely. This is why the window values were re-calibrated for the gesture bot remote.
  • With the pick and place remote, drive to the orange block, lower the lift, close the gripper, carry the block to the drop zone and open the gripper.
