Maze Solving Robot

Level 2 · Arduino · 5 line sensors · left hand rule

The robot explores a black-line maze by always preferring the leftmost way. It notes every decision at a junction (L, S, R) and every dead-end U-turn (U). The shortest-path version then removes each detour from that list and drives the maze again without a single wrong turn. The return version drives back to the start.

Green circle: start (a dead end). Black square: end box. The dashed trail is where the robot has driven.

What the sensors see

Five sensors in a row read 0 over the black line. At every node the sketch first reads the pattern, then inch()es forward 0.3–0.5 s and reads again to see whether the line continues straight ahead:

pattern  after inch   meaning              left hand rule   recorded
11011    -            straight line        forward          -
11111    -            dead end             U-turn           U
11000    11111        right turn only      right            -
11000    11011        straight or right    straight         S
00011    11111        left turn only       left             -
00011    11011        straight or left     left             L
00000    11111        T junction           left             L
00000    11011        4-way crossing       left             L
00000    00000        end box              stop             E

Shortest path: removing detours

Every U marks a dead end. The three letters around it (turn in, U-turn, turn out) all happen at one junction, so they can be replaced by the single turn the robot should have made there. Treating turns as angles (S = 0°, R = 90°, U = 180°, L = 270°) the replacement is simply their sum:

L U L  -> 270+180+270 = 720 = 0   -> S
L U S  -> 270+180+0   = 450 = 90  -> R
S U L  ->   0+180+270 = 450 = 90  -> R
L U R  -> 270+180+90  = 540 = 180 -> U
S U S  ->   0+180+0   = 180       -> U
R U L  ->  90+180+270 = 540 = 180 -> U

simplify_path() applies this while it reads the path, so nested detours collapse too. On the shortest run the robot follows the line as usual; at each junction that offers a choice it takes the next letter. For the return trip reverse_path() reverses the list and swaps L and R, because a left turn on the way in is a right turn on the way back.
