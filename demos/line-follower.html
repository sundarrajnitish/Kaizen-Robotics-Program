Line Following Robots

Level 1 · ATmega16 · Embedded C

Two IR sensors straddle a black line. Each loop the firmware reads PIND, matches the bit pattern against its cases and writes a motor pattern to PORTB. Pick a firmware to compare the basic line follower with the obstacle-aware and competition versions.

How it works

  1. Each line sensor shines IR at the floor. White reflects (reads 0), the black line absorbs it (reads 1).
  2. The sensors sit either side of the line, so on a straight both read 0 and the robot drives forward.
  3. When the line curves it slides under one sensor; the robot spins towards that side until the line is centred again.
  4. When both sensors see black the robot is on a crossing: it beeps and drives straight over it.

Firmware variants

  • LFR.c – the basic two-sensor line follower.
  • OARLFR.c – adds a front proximity sensor on PD1 and waits while the path is blocked.
  • ALFR.c – competition robot: stops with an alarm at obstacles and runs at a potentiometer-set PWM speed while its side sensor sees a cave wall.
  • ALFR(Arduino).ino – the same behaviour written with the Arduino API and analogWrite().

Try this

  • Click on the track in front of the robot to drop an obstacle (obstacle-aware firmware only). Click it again to remove it.
  • Drag the robot to move it, or drag the blue dot to turn it. Put it on the line at an angle and watch it recover.
  • With ALFR.c, move the cave pot: higher readings mean a longer PWM off-time and a slower robot in the cave.
