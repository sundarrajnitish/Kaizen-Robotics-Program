Kaizen Robotics Program – Live Demos

runs in your browser, no install

Every robot from the program running in a simulator. Each demo runs a JavaScript port of the robot's firmware, one case per branch of the real C / Arduino code, and shows the input pins, the output pins and which line of logic is active. Use these pages to see what each robot does and how its code decides.
