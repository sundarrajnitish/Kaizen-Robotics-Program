Table Top Robot

Level 1 · ATmega16 · Embedded C · TTR.c

Four downward-facing IR sensors, one at each corner, read 0 while they see the table and 1 once they are past the edge. The robot roams the table and backs away or turns whenever a sensor goes over the edge.

Drag the robot to the edge (or drag the blue dot to aim it off the table) and watch it save itself. S1/S2 are the front sensors, S3/S4 the rear ones.

Microcontroller I/O

Motors

How it works

  1. On the table all four sensors read 0, so PIND is 0b11110000 and the robot drives forward.
  2. If a front sensor leaves the table the robot reverses and turns away; if a rear sensor leaves it drives forward and turns.
  3. The manoeuvres are timed with _delay_ms(), so the exact distances depend on the motor speed.
  4. Patterns that have no case (for example two diagonal sensors off at once) leave the motors doing whatever they did last.
